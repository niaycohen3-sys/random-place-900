# 🎲 מקום רנדומלי — 900 מטר

אתר פשוט, מהיר ורספונסיבי בעברית (`dir="rtl"`) שמגריל עבורך **מקום אחד בלבד** — קפה, מסעדה או בר — ברדיוס של **900 מטר** מנקודה שתבחר.

**העיקרון:** מינימום בחירה, מקסימום רנדומליות. אין "מומלצים", אין טופ 5, אין מיון לפי דירוג. ההגרלה אחידה מתוך כל המקומות ברדיוס. המתג היחיד הוא סינון אופציונלי לדירוג 3+ (כבוי כברירת מחדל). כפתור "נסה שוב" מגריל מקום אחר באותו רדיוס.

## איך קובעים נקודה (3 דרכים)
1. **מיקום בזמן אמת** — כפתור "המיקום שלי" (Geolocation).
2. **כתובת ידנית** — הקלדה עם השלמה אוטומטית (Nominatim).
3. **סיכה על המפה** — לחיצה או גרירת הסיכה על מפת Leaflet אינטראקטיבית; עיגול של 900 מטר מסומן על המפה.

התוצאה מוצגת על המפה ובכרטיס: שם, קטגוריה, כתובת, מרחק, דירוג (אם זמין), פתוח/סגור (אם זמין), וכפתורי ניווט ל-Google Maps ול-Waze.

## סטאק ולמה
Vanilla JS + Leaflet + OpenStreetMap — בלי build, בלי תלויות, **בלי API Key בכלל**:

| שירות | תפקיד | עלות |
|---|---|---|
| Leaflet + Esri World Street Map | מפה, סיכה, עיגול רדיוס | חינם, בלי מפתח |

> למה לא ספקי האריחים המובנים מאליהם? tile.openstreetmap.org חוסם הטמעה באפליקציות (403 "Access blocked"), ו-CARTO מטביע סימן מים "API KEY REQUIRED" בלי מפתח בתשלום/רישום. אריחי Esri World Street Map מאפשרים הטמעה חינמית עם קרדיט, בלי מפתח (סדר הצירים ב-URL שלהם הוא `z/y/x`). נתוני המקומות עצמם עדיין מ-OpenStreetMap דרך Overpass.
| Overpass API | שליפת קפה/מסעדות/ברים ברדיוס | חינם |
| Nominatim | גיאוקודינג + השלמת כתובות | חינם |

**מגבלות המקור החינמי (חשוב לדעת):** ב-OpenStreetMap הדירוג (כוכבים) קיים רק לחלק קטן מאוד מהמקומות, וגם שעות פתיחה חלקיות. לכן: דירוג/סטטוס מוצגים רק כשקיימים, והמתג "3+" מסנן רק מקומות עם דירוג ידוע. הכיסוי של עצם המקומות בישראל טוב בערים, דליל יותר בפריפריה.

## הרצה מקומית
אין שלב build. כל שרת סטטי עובד:

```bash
cd random-place-900
python3 -m http.server 8000
# או: npx serve .
```
ואז לפתוח http://localhost:8000

> שים לב: כפתור "המיקום שלי" דורש HTTPS או localhost (מגבלת דפדפן, לא של האתר).

## חיבור מפתח Google Places (אופציונלי — רק אם רוצים דירוגים ושעות מלאים)
הגרסה הנוכחית **לא צריכה מפתח**. אם תרצה לשדרג ל-Google Places:

1. היכנס ל-[Google Cloud Console](https://console.cloud.google.com/) וצור פרויקט חדש.
2. הפעל חיוב (Billing) לפרויקט — Google דורשת כרטיס, יש מכסת שימוש חינמית חודשית.
3. בתפריט **APIs & Services → Library** הפעל: **Places API (New)**, **Maps JavaScript API**, **Geocoding API**.
4. ב-**APIs & Services → Credentials** צור **API Key**, והגבל אותו: Application restriction = האתר שלך (HTTP referrers), API restriction = שלושת ה-APIs שלמעלה בלבד.
5. העתק את `.env.example` ל-`.env` ומלא:
   ```
   VITE_GOOGLE_MAPS_API_KEY=המפתח_שלך
   ```
6. **בפריסה:** הגדר את אותו משתנה כ-Secret/Environment Variable של ספק הפריסה (GitHub: Settings → Secrets and variables → Actions; Netlify/Vercel: Site settings → Environment variables). **לעולם אל תעלה `.env` אמיתי ל-Git** — הוא כבר ב-`.gitignore`.

## פריסה
- **GitHub Pages:** העלה את הקבצים לריפו → Settings → Pages → Deploy from branch `main`, תיקיית שורש. האתר חי תוך דקות, ב-HTTPS (נדרש למיקום).
- **Netlify / Vercel:** גרור את התיקייה או חבר את הריפו — בלי build command, תיקיית publish = שורש.
